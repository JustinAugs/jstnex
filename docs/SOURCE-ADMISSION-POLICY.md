# 真实来源准入规则（L14，TASK 09 的约束）

2026-11-23。当前业务 JSON 未新增真实数据或来源。本规则是采集与发布门槛，不是已完成取源的声明。

## 1. 当前可执行校验

`npm run validate:data` 共用 `lib/data/provenance.ts` 的校验函数：

- 缺省/null/curated 继续合法，不用占位来源冒充官方记录。
- official/dataset 必须有非空 name、url、retrievedAt。
- URL 必须能解析为 HTTP(S)，有主机，无用户名/密码，无首尾空白；拒绝脚本、本地文件和残缺链接。
- retrievedAt/updatedAt 如提供，必须是有效公历日期 YYYY-MM-DD，含闰年判断，年份 0000 不接受。
- 语法正确不证明链接可访问、来源权威或许可有效；这三项必须逐源人工核实。
- 企业目录、国家详情、概念卡共用 SourceField。curated 不显示空来源；真实来源显示名称与安全链接。首页整卡链接不嵌套来源链接，完整来源在企业目录展开区读取。

隔离测试：`node scripts/check-data-contracts.mjs`、`node scripts/check-component-contracts.mjs`。生产 JSON 不写测试值。

## 2. 每个采集源的必交记录

TASK 09.00 对首批每个来源提交一份来源清单，包含：

| 项目 | 要求 |
|---|---|
| 身份 | 发布机构、数据集/报告标题、确切页/表/字段、原始URL，优先原发布方 |
| 许可 | 许可原文地址、再发布/署名/缓存/自动获取条件；公开可读不自动等于可再发布 |
| 时间 | 数据的统计期间、源发布时间、源修订时间、retrievedAt、本站核对updatedAt 分开保存；缺失明确未知 |
| 口径 | 指标定义、单位、币种、现价/不变价、财政/自然年、地区覆盖及排除范围 |
| 处理 | 原始值、解析结果、转换公式/比例、精度、清洗版本、原始文件校验值 |
| 更新 | 上游周期、本站复核周期、负责人、失效/受限/延迟状态与重试预算 |
| 对外展示 | 哪些字段获来源支持、展示标签、日期/口径、过期提示、许可署名位置 |

`retrievedAt` 是实际取用日期，不能冒充统计期或源发布时间。`updatedAt` 是本站最后核对日期，不能冒充上游修订。二者不武断规定先后顺序；同日抓取也不证明是最新统计。时间未知则不填写猜测值。

## 3. 字段级事实与发布门槛

现有记录级 Provenance 只适合一个来源确实支持同一条定性内容的情况。一条来源不能默认支持记录里全部指标。首批多指标/多来源数据必须先提交字段级模型方案，再实现校验和 UI；当前 schema **尚不接受新的数值指标契约**。

字段级设计至少绑定 recordId + field/metricId + sourceId；事实保留 value/status、unit、period、coverage 和 revision。币种、数量单位、时间区间不得混用；缺失/不可比/受限与数值零不同。采集失败不得把旧值覆盖成零或编造新鲜日期。

准入流程：先核原始表头/脚注与定义，再对照字段字典及单位换算，最后逐条复核发布样本。出现口径/单位不匹配则拒绝发布，不能只靠 URL/日期校验判为通过。没有字段模型与针对性负向测试前，不上线金额、吞吐量、排名等新事实。

冲突规则：保留各来源原值及版本；先比较期间、单位、覆盖与修订。相同口径优先原发布机构最新修订；不同口径并列注明、禁止取平均或择有利数值。无法解释的冲突保留缺失/争议状态，不发布单一权威数字。

许可不明、来源失效、无法追溯具体表/字段时：阻止新增真实事实发布；可保留明确标注的旧定性教学内容。curated 不是绕过统计发布审核的通道。
