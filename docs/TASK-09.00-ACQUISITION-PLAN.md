## 09.00.1 目标与首批范围

首批要验证“一个可追溯来源 → 可重放获取 → 严格字段校验 → 国家详情显示 → 更新/回退”的完整链路，而非一次覆盖所有贸易数据。

确定的先行试点：World Bank WDI source=2，指标 `NE.EXP.GNFS.CD`，中国CN/CHN、美国US/USA，2022—2024三个自然年，共6个观测。用途是国家详情的**宏观出口背景**。国家与指标是显式白名单，保持现有8国目录及地区顺序。

这个指标同时含货物和服务、按当年价格计美元，经济所有权转移不必伴随实物跨境。它不能当作港口吞吐量、实物货运量、双边航线流量、全球贸易总额、纯商品出口或供应链实力排名。也不把它输入企业EOQ等教学计算器。

先行范围不含：企业财务数字、港口指标、全世界覆盖、实时数据、国家搜索、地图/图表、数据库/API后端或AI。后续扩展要以用途与来源准入为依据；不为凑地区均衡或消警告扩数据。

## 09.00.3 已核实来源与样本结果

详见[来源登记](TASK-09.00-SOURCE-REGISTER.md)与[实测清单](evidence/task09-2026-11-23/manifest.json)。

- WDI官方指标页明确列出CC BY-4.0；API无需密钥。逐指标许可和WB附加条款均纳入来源登记，不能只用全站“开放数据”推断所有来源可复用。
- 官方API的source=2元数据、指标定义及CN/US 2022—2024样本均实际读取，样本6条均为非空值，响应完整一页。上游响应的lastupdated是2026-11-11，**是数据集更新标签**，不是每个观测的发表/修订日期。
- 追加读取2023—2025窗口发现US 2025为null；不能将其补零、预测或偷偷回填2024并标成2025。因此首批采用已验证共同完整的2022—2024固定窗口，不称“最新2025数据”。同时保留缺失样本供后续负向测试。
- API的unit为空，但官方指标定义明确为current US$。单位由审核后的指标注册表给定为USD、scale=1、current prices；不能从网页“Millions”显示标签猜测API已缩放。
- Python默认TLS证书链读取失败；系统curl保留证书验证读取成功。此为本机客户端信任库差异，未关闭TLS验证。正式采集器必须使用正常可信CA，证书异常按失败处理，不能用verify=False或-k。

这些请求是09.00的小规模可行性取样，原始响应仅在docs/evidence，未被页面加载、未加入生产业务JSON，不能报告09采集流水线已完成。

## 09.00.4 架构决定

1. 保留现有业务内容。新增来源注册表、指标注册表、观测数据和采集清单作为独立层；具体草案见[字段契约](TASK-09.00-DATA-CONTRACT.md)。
2. 记录级Provenance只支持被该来源覆盖的同质定性内容。新指标必须逐观测关联 sourceId/indicatorId/recordId；不给国家整条档案挂一个WDI来源来替summary、risk等文字背书。
3. 获取层与页面解耦。初期采用维护者手动运行的Python标准库脚本（HTTP、JSON Decimal、hashlib），不引爬虫框架；构建/请求时不访问上游API。网络失败不影响已有站点。
4. 原始层保留精确字节与SHA256；清洗层保留十进制值、单位、期间、来源与状态；发布层仅消费已验收的快照。采集成功、快照发布与部署是三个不同状态。
5. 只使用已批准的官方API和白名单主机；没有登录/付费/账号需求。不启用Agent Reach、媒体工具、浏览器抓取或定时任务作为隐藏依赖。
6. 所有现有界面继续双语；新数据标题、期间、USD/当年价格、取用/核对日期、提供机构、许可和原始链接必须可读。新UI实施时再按既有设计和browser验收流程执行。

## 09.00.5 更新、失败与冲突

- 发布首批窗口固定2022—2024；上游修订仍可能改变历史值。每月人工复核一次为**后续运维建议**，本轮不创建自动任务。09.06先实际演练一次重取及回退。
- 网络超时、429、5xx最多初次+2次重试；遵守Retry-After，单次等待超过60秒则记录deferred并结束，下一次人工运行再处理；401/403、TLS、结构/许可异常直接失败，不轮换代理绕过限制。
- URL参数和上限由白名单决定：仅source2、一个指标、两个经济体、三个年份；分页必须校验page/pages/total，禁止只处理首页就称完整。
- 同一来源同期间的修订：保存旧批次、差异和新hash，复核后替换发布清单。不同单位/期间/覆盖的值不可择优或取平均，不自动融合第三方来源。
- null保存为missing；采集失败不产生新观测，不覆盖旧值，不刷新旧数据retrievedAt或checkedAt。旧快照保留真实期间与日期，界面用“最后核对”而非无证据的“实时/最新”。
- 验收通过后以候选目录→校验→显式发布manifest原子切换，失败保持上一可用批次；不得半写生产JSON。首批快照小规模可入Git，增长后再规划存储，不提前做TASK10。
